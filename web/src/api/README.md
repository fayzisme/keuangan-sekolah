# Generated API Client

Folder ini adalah lokasi client TypeScript yang di-generate dari OpenAPI Laravel (`dedoc/scramble`).

Aturan:
- Jangan edit file di `src/api/generated/` secara manual.
- Jalankan `npm run generate:api` atau `make api-generate` setelah kontrak API berubah.
- Seluruh fitur React harus memakai client ini, bukan `fetch`/`axios` manual tersebar.
